## About
Student Tech Guide is a student-focused website created to share useful information about AI tools that can support college study, research, productivity, and everyday academic tasks.

## Purpose
The website aims to help college students discover technology tools that may make studying and organizing academic work easier.

## Features
- Information about AI tools for college students
- Student-focused descriptions and use cases
- A simple website that can be accessed online
